# Replit Discoverability Skill

Portable website SEO / AEO / GEO build-and-audit instructions for Replit Agent. Contains NO website-specific domains, brand settings, accounts, or client information.

## Recommended: workspace skill

In Replit open **Workspace Settings > Customization > Skills** and choose to upload an existing skill. Upload the `replit-discoverability` skill folder or the supplied ZIP, according to the current uploader's accepted format. If uploading a file rather than a folder, use `replit-discoverability/SKILL.md` and add the two accompanying reference files in the same relative paths. Workspace skills may then be selected in Agent via `+` or invoked by `/replit-discoverability` where supported.

## Alternative: project installation

Copy the `replit-discoverability` folder under `.agents/skills/` in a Replit project's root so `.agents/skills/replit-discoverability/SKILL.md` exists. This is the documented project-level skill location. It is not a substitute for workspace-wide installation.

## Example prompts

- `/replit-discoverability Build It Right: Plan the public SEO/AEO/GEO architecture for this new website. Inventory public/private routes first. Do not change code or publish until I approve the plan.`
- `/replit-discoverability Audit and Repair: Review this deployed site's indexability and accessible performance. Read-only report with specific evidence and smallest fixes. No scans, edits or publication without authorization.`
- `/replit-discoverability Investigate the precise Google Search Console status for [exact URL]. First compare canonical, redirects, robots, sitemap, initial HTML and the Search Console evidence I provide.`

## Safety and claims

The skill provides process guidance; it cannot guarantee indexing, rankings, AI citations, or perfect accessibility/performance. An installed skill does not perform work continuously or alter publishing permissions. Replit's current interface and entitlements may differ by plan.

Official format documentation: https://docs.replit.com/replitai/skills and https://replit.com/blog/custom-skills

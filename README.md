# Replit Discoverability Skill

A reusable Replit Agent skill for technical SEO, answer-engine optimization (AEO), and generative-engine discoverability (GEO), with accessibility, privacy, and real-world performance checks.

## Contents

- [Installable skill folder](replit-discoverability/): SKILL.md plus its references and usage notes.
- [Technical checklist](replit-discoverability/references/technical-checklist.md)
- [Acceptance report format](replit-discoverability/references/acceptance-report.md)

## Use it

Use the replit-discoverability folder as the skill directory. For project-level use, copy it under .agents/skills/. For workspace-wide use, upload the skill folder through Replit's current workspace skill-management flow. Confirm the current uploader's supported format and interface before installation.

The skill is process guidance. It cannot guarantee search indexing, rankings, or AI citations. Review the skill's permission and deployment rules before applying changes to a site.
